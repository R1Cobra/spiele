🕷️ Spider Solitär

Baue in jeder Spalte eine Reihe von König bis Ass – in der gleichen Farbe.

❓ So wird gespielt
  • Ziel: 8-mal eine komplette Reihe König → Ass in der gleichen Farbe bauen. Ist eine Reihe fertig, wird sie automatisch abgeräumt.
  • Bewegen: Karte antippen (sie und alles darunter wird angehoben), dann die Zielspalte antippen. Nochmals antippen hebt die Auswahl auf.
  • Ablegen: Eine Karte darf auf die nächsthöhere Karte gelegt werden (7 auf 8), egal welche Farbe. Auf eine leere Spalte darf alles.
  • Mitnehmen: Mehrere Karten kannst du nur zusammen bewegen, wenn sie lückenlos absteigen und die gleiche Farbe haben.
  • Karten geben: Der Knopf legt auf jede Spalte eine neue Karte – das geht nur, wenn keine Spalte leer ist. Fünf Runden sind drin.
  • Punkte: Start 500, jeder Zug kostet 1 Punkt, jede fertige Reihe bringt 100.
